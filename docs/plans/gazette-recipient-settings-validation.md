# Gazette recipient settings validation — 8 October 2026

Based on merged master `6ab64cc` (spreadsheet generator PR #88), branch
`feat/gazette-recipient-settings` implements only shared recipient configuration.
The initial value is unset; a court mailbox is never used as a recipient default.

## Contract and persistence

- Admin-only GET/PUT `/caseworker/gazette-settings`.
- PUT accepts exactly `recipientEmail` and a non-negative integer `revision`.
  One trimmed address, maximum 254 characters and local part at most 64; blank,
  null, multiple addresses, display-name forms and header injection are refused.
- V33 seeds the singleton at revision 0 and adds a separate change history with
  before/after addresses and verified caller attribution. No existing migration changed.
- A row lock and original revision prevent lost updates, including simultaneous
  first saves. Stale writes return 409. An unchanged current address is a no-op.
- Setting and change history are atomic; subjects remain private to persistence.
